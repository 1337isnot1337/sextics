# Leaderboard

The board is generated from validated accepted solution records. Each distinct accepted instance gives one point to its direct PR author. Do not edit scores manually or award credit merely for local compilation, an unmerged proof, or a status flag.

`leaderboard/accounts.json` provides optional display names and locally bundled avatars. Unknown contributors receive a text avatar and their GitHub login. `leaderboard/credits.json` is generated by `scripts/build-content.py` from acceptance-backed records. The website has no GitHub API dependency at runtime.

Solver portraits link to the contributor's leaderboard entry; the construction header links to the actual merged PR from its receipt. The explanation records collaborators and prior mathematical sources. Documentation contributions retain their authorship but do not add solve points.
