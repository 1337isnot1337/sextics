Start with the Fermat equation and couple the pair \(X_0,Y_0\) to a third coordinate by adding
\[
Y_1^2\cdot(X_0^4-X_0^2\cdot Y_0^2+Y_0^4).
\]
The quartic in parentheses is a cofactor of \(X_0^6+Y_0^6\). Thus the perturbation is structured, but it genuinely changes the active derivative equations: it is not simply an arbitrary polynomial in variables that the old field never touches.

The target changes along with the sextic:
\[
A=X_0^3\cdot X_1\cdot X_2\cdot Y_0
+\frac13\cdot X_0\cdot X_1\cdot X_2\cdot Y_0\cdot Y_1^2.
\]
This is the important comparison with the diagonal control. Requiring exactly the old target after a deformation is a different problem from transporting a class according to a prescribed law. The second summand records that distinction explicitly rather than concealing it in a choice of coordinates.

This pair was selected as a prediction from the structure of a known pair construction. Its purpose is to test whether an intelligible certificate can survive a coupling that defeats the immediate subset-Euler shortcut. Indeed, for either displayed target monomial, the coordinate subsets with the required target-degree balance fail the necessary zero-or-six weight condition on the coupled equation. That excludes that specific elementary formula, not rational primitives in general.

A successful treatment should explain why this perturbation is compatible with the target correction and which other perturbations have the same property. [The moving polarized-contact example](#case/polarized-contact-deformation-d2) asks a related question with a different starting geometry. Together they distinguish three useful tasks: solving one fixed class, preserving it under deformation, and transporting it while allowing the target to move. The atlas's acceptance condition concerns the exact displayed tuple in each case.
